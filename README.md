# Car Sales Forecasting using Linear Regression

## Project Overview

This project analyzes and forecasts monthly car sales using Linear Regression based on a Kaggle dataset.

## Features

* Data preprocessing
* Trend analysis
* Linear Regression model
* Visualization of results

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Dataset

Kaggle Car Sales Dataset

## Output

* Graph showing actual vs predicted sales
* Forecasted future values
